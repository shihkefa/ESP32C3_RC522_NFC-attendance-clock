# v1.3.34 驗證結果

## 原始碼驗證紀錄

- ESPHome 2026.8.1／ESP-IDF 5.5.5／ESP32-C3 完整編譯成功。
- 自行設定版韌體映像 1,308,458 bytes（BIN 另有對齊），程式區使用 83.2%；靜態 RAM 199,922 bytes，使用 62.2%。
- C++ 函式搭配模擬 Flash 的驗證紀錄包含：補登早期時間後重新掃描、循環覆寫、紀錄銜接、管理密碼錯誤、員工與打卡類型錯誤、日期邊界、禁止未來時間、還原期間及無有效時間時拒絕補登。
- 網頁 JavaScript 語法與提交函式驗證包含：UTC+8 時間轉換、API 參數、提交後清除密碼與恢復按鈕。
- 使用本版 `attendance_partitions.csv`，每筆刷卡紀錄為 32 bytes，透過寫入序號定位下一筆資料。
